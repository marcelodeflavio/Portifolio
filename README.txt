# Marcelo de Flávio — Portfólio V2

Ficheiros:
- `index.html` — página principal
- `style.css` — design responsivo
- `script.js` — menu, relógio, tema, animações e progresso
- `cv.html` — CV próprio, pronto para imprimir/guardar como PDF

## Publicação no GitHub Pages

1. Coloque os quatro ficheiros no mesmo diretório do repositório.
2. Confirme que `index.html` está na raiz publicada.
3. Em GitHub → Settings → Pages, selecione a branch/pasta usada pelo projeto.
4. O `index.html` será a página inicial.
5. O CV estará em `/cv.html`.

## Imagem de perfil
O design atual usa um monograma `MF`, por isso funciona mesmo sem uma fotografia. Se quiser adicionar uma fotografia depois, ela pode substituir o bloco `.portrait-card`.

## Observação
O conteúdo textual foi baseado nas informações fornecidas por Marcelo de Flávio no material de origem. Não foram adicionados contactos, certificados, cargos ou experiências que não constavam nesse material.
